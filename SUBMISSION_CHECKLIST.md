# Submission Checklist

## Requirements

- [x] User authentication
- [x] User authorization
- [x] Create tasks
- [x] Read/list tasks
- [x] Update tasks
- [x] Delete tasks
- [x] To do / In progress / Completed statuses
- [x] Responsive web/mobile layout
- [x] REST API integration
- [x] Persistent database
- [x] Dynamic task data
- [x] Real-time updates are optional and are not required for this version

## Demo flow

1. Register User A.
2. Create 2–3 tasks.
3. Edit a task.
4. Change task status and priority.
5. Search and filter tasks.
6. Log out.
7. Register User B.
8. Confirm User B cannot see User A's tasks.

## Before submission

- Confirm the backend starts on port 5000.
- Confirm the frontend opens on port 5173.
- Confirm account registration works.
- Confirm login/logout works.
- Confirm a page refresh keeps saved tasks.
- Confirm User B has a separate task list.
